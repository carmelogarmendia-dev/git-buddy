# Changelog de Git Buddy

## [1.0.0] - 2025-05-01

### Añadido
- Lanzamiento inicial de Git Buddy
- Selector de carpetas nativo de Windows
- Conexión con GitHub mediante token de acceso personal
- Clonado de repositorios (públicos y propios)
- Commit y push a GitHub
- Detección visual de cambios Git (colores)
- Ignorar archivos con click derecho
- Proyectos recientes (localStorage)
- Notificaciones elegantes (toasts)
- Sistema de cierre limpio con página de instrucciones

### Portabilidad
- 100% portable (no requiere instalación)
- No necesita PHP en el sistema
- Funciona desde cualquier disco o pendrive
