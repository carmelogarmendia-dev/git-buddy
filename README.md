# 📦 Git Buddy

> **"Git no debería ser un obstáculo para crear cosas increíbles."**

**Git Buddy** es una herramienta visual de escritorio diseñada específicamente para **Windows**. Transforma la complejidad de Git en una experiencia intuitiva, permitiendo que diseñadores, sitebuilders y desarrolladores junior gestionen sus repositorios de GitHub sin tocar una sola línea de comandos.

## 🎯 Nuestra Filosofía
Git es una herramienta increíblemente poderosa, pero su curva de aprendizaje puede ser intimidante. Git Buddy nace para democratizar el control de versiones:
*   **Accesible:** Interfaz pensada para humanos, no para máquinas.
*   **Visual:** Estados claros (🟢 nuevo, 🟡 modificado) identificables al instante.
*   **Seguro:** Operaciones simplificadas para evitar errores accidentales.
*   **Sin Terminal:** Todo lo que necesitas está a un clic de distancia.

## 🛠️ Stack Tecnológico
Git Buddy es ligero y potente gracias a su arquitectura moderna:
*   **Core:** PHP 8.x (Ejecución local ultrarrápida).
*   **Frontend:** Vanilla JS & CSS3 (Sin frameworks pesados, máxima velocidad).
*   **Motor:** Git CLI (Utiliza tu instalación local de Git de forma transparente).
*   **UI:** Bootstrap 5 (Interfaz limpia y responsive).

---

## 🔒 Seguridad y Privacidad
Tu seguridad es nuestra prioridad:
*   **Almacenamiento Local:** Tus tokens de GitHub se guardan cifrados localmente en tu equipo (`app/storage/`).
*   **Sin Nube Intermedia:** La comunicación es directa entre tu equipo y GitHub.
*   **Código Abierto:** Puedes auditar exactamente cómo se manejan tus datos.

---

## 📥 Instalación (Portable)
Git Buddy es **100% portable**. No requiere instalación ni permisos de administrador.

1.  **Descarga:** Obtén el `.zip` desde la sección de [Releases](https://github.com/tu-usuario/git-buddy/releases).
2.  **Extrae:** Descomprime en cualquier carpeta (ej. `C:\Herramientas\GitBuddy`).
3.  **Lanza:** Doble clic en `GitBuddy.vbs`.

---

## 🚀 Guía Rápida

### 1. Configuración Inicial
Haz clic en el botón **GitHub** y pega tu *Personal Access Token*. Si no tienes uno, la app te guiará paso a paso para crearlo en 30 segundos.

### 2. Flujo de Trabajo
1.  **Abre** tu proyecto.
2.  **Selecciona** los archivos que quieres subir (o deja que Git Buddy los detecte todos).
3.  **Escribe** un mensaje breve (ej: "Añadido nuevo logo").
4.  **Pulsa** "Commit y Push". ¡Listo!
